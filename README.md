# Project 1 — Rule-Based AI Chatbot

## Objective
Create a simple chatbot that responds to predefined user inputs using `if-elif-else` logic and a continuous loop.

## Requirements
- Python 3.8 or later
- No third-party packages required

## Run
1. Extract this ZIP.
2. Open a terminal in this folder.
3. Run: `python main.py`
4. Type `help` to see example topics.
5. Type `exit` to stop the chatbot.

## Example
You: hello
RuleBot: Hello! Good morning. How can I help you?

You: what is your name
RuleBot: I am RuleBot, a simple rule-based AI chatbot.

You: joke
RuleBot: Why did the computer go to the doctor? Because it had a virus!

## How it works
The chatbot converts input to lowercase, checks it against predefined rules, and returns a matching response. It does not learn from data; it follows programmed rules.
